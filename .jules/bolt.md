## 2026-03-30 - Contiguous Byte Stream Slicing in MP3 Frame Extraction
**Learning:** Slicing thousands of individual 144-byte frames in Python `bytes` streams creates massive memory allocation and list join overhead. Slicing contiguous spans of valid frames reduces allocations from O(N_frames) to O(N_segments).
**Action:** When scanning binary streams (MP3/PCM/WAV) in pure Python, track contiguous valid index spans (`seg_start` to `idx`) rather than slicing per element/frame.

## 2026-08-23 - Fast-path Substring Guards Before Regex Executions
**Learning:** Executing compiled C-regex substitution methods (e.g., `_RE_HYPHEN_BREAK.sub`) on large text strings incurs noticeable invocation overhead even when the target pattern is absent. Checking substring presence first in pure C Python (`if '-\n' in text:`) avoids expensive regex engine invocations.
**Action:** Guard string regex replacements with fast `in` substring checks when target tokens are sparse/absent in the vast majority of input documents.

## 2026-10-17 - Single-Pass DOM Priority Bucket Traversal
**Learning:** Checking semantic HTML container priority rules by running 9 separate depth-first search passes over parsed DOM trees creates redundant node visitor overhead on large web documents. Accumulating matching nodes into priority buckets in a single tree walk eliminates $8 \times N$ redundant recursive function calls.
**Action:** When evaluating priority selector rules over a custom tree/DOM structure, perform a single pass into indexed priority buckets rather than executing multiple predicate searches.
